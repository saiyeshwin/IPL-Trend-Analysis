# IPL-Trend-Analysis
## IPL Death Overs Analysis & Prediction

1. **Predicts Match Winners**: Calculates the percentage chance of a chasing team winning.
2. **Death Over Focus**: Specifically analyzes the final 5 overs (last 30 balls) of the game.
3. **Live Match Tracking**: Uses runs needed, wickets left, and required run rate for predictions.
4. **Machine Learning Logic**: Uses historical IPL data to compare the current game to past results.
5. **Visual Momentum**: Generates charts to show how the win probability shifts ball-by-ball.
